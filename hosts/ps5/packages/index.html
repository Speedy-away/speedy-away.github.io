Console setup and troubleshooting

Use an existing compatible homebrew environment. The browser opens the local native tools after they have been set up.

  1. Install ezRemote Client 2.18. Start compatible websrv before opening ezRemote Client. Start the bundled background server and keep the console awake.
  2. Use the direct URL download feature in ezRemote to save the pinned downloader companion to /data/homebrew/ezremote-client/assets/whatsite-ps5.html. Its direct URL is https://speedy-away.github.io/console/ps5/whatsite-ps5.html.
  3. In ezRemote, save the pinned package helper to /data/homebrew/ezremote-client/assets/whatsite-package-installer-ps5.html. Enter https://speedy-away.github.io/downloads/helpers/host-package-installer/ps5/48aa27c4c9899826/whatsite-package-installer-ps5.html as its direct URL. Keep the client web service running on port 9090.
  4. Choose a PKG below and open Save on PS5. Choose a verified destination in the downloader, confirm the transfer and wait for its completion report.
  5. Open Verify & install PKG on the completed transfer. Verify the expected size and saved file path, review the confirmation and explicitly choose Install. For an already saved PKG, use Open installed package helper on this console.

Open installed downloader on this console. If the local page cannot open, check the companion path and that the matching ezRemote Server is running on port 6701. If the save folder is missing, choose Prepare download folder in the local downloader.

PS5 needs a compatible Direct Package Installer running in addition to ezRemote. Check this package against the installed environment.

The helper checks filename, size and partial download status. The SHA-256 below is a reference for verifying the full saved file. A native acknowledgement still requires checking the installation result on your console.
