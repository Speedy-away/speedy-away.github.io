Set up console downloads

Saving to your PS5 requires ezRemote and a compatible homebrew setup. Download file opens the original file in your browser. If the browser refuses the file type, use ezRemote.

First-time setup on PS5 requires a compatible homebrew environment. If you already have Payload Manager, ezRemote documents a loader that installs or updates the client from the console. Check that the client version matches the steps below.

  1. Open ezRemote Client 2.18 on the PS5 after your compatible ELF listener is running on port 9021. Keep ezRemote open so it can start its bundled services. Run compatible websrv on port 8080 for the Download Centre’s save folder checks. In the console browser, choose Open ezRemote Web UI. Choose Download URL, then use Change to select the destination folder. Enter the filename and direct URL shown below.
  2. In the ezRemote Web UI, download the latest downloader companion to /data/homebrew/ezremote-client/assets/whatsite-ps5.html. Its direct URL is https://speedy-away.github.io/console/ps5/whatsite-ps5.html.
  3. Choose Save on PS5 for a file, prepare or choose a writable destination and press Save to console. The local page shows live progress. When the save completes, eligible files show Extract or Install PKG.

Open the ezRemote Web UI on port 9090 first if you need to install the companion. After setup, choose Open download queue. If it cannot open, check the companion path and that the matching ezRemote Server is running on port 6701. If the save folder is missing, choose Prepare a storage folder.

To install a saved PKG, open the package setup and use the compatible installer. Keep enough storage for both a download and any installed or extracted copy. PS5 installation uses the Direct Package Installer bundled with ezRemote.

Update the PS5 downloader

Keep ezRemote Client and its background server running. Choose Download update, then return here if the browser opens a blank page. Choose View update progress to see when Apply is ready.

View update progress

Update from an older downloader

If View update progress opens the regular queue, wait for the update to complete there, then return here and open the staged update. This installs the version that supports the progress screen.

If the browser blocks the update request, use the direct URL under Set up console downloads.

Extract archives on PS5
  1. Keep websrv, the installed ezRemote Client and its bundled background server running.
  2. Choose Archives, select a file and wait for the local downloader to report the save complete.
  3. In the downloader, choose Extract, then Verify checksum & extract into new folder. If you reopened the downloader, select the original save folder and choose Verify & extract saved copy when it appears. Reviewed extraction keeps your original archive and creates a new folder.
  4. If the archive contains a compatible PKG, open the extracted folder in the ezRemote Web UI and select that PKG for installation. Check the result on your console.

The verified extraction action is limited to reviewed archives up to 32 MiB. For larger or unreviewed archives, inspect the saved file in the native file manager before extracting it there.

Install PKGs on PS5

Use an existing compatible homebrew environment. The browser opens the local native tools after they have been set up.

First-time setup on PS5 requires a compatible homebrew environment. If you already have Payload Manager, ezRemote documents a loader that installs or updates the client from the console. Check that the client version matches the steps below.

  1. Open ezRemote Client 2.18 on the PS5 after your compatible ELF listener is running on port 9021. Keep ezRemote open so it can start its bundled services. Run compatible websrv on port 8080 for the Download Centre’s save folder checks. In the console browser, choose Open ezRemote Web UI. Choose Download URL, then use Change to select the destination folder. Enter the filename and direct URL shown below.
  2. In the ezRemote Web UI, download the latest downloader companion to /data/homebrew/ezremote-client/assets/whatsite-ps5.html. Its direct URL is https://speedy-away.github.io/console/ps5/whatsite-ps5.html.
  3. In ezRemote, save the pinned package helper to /data/homebrew/ezremote-client/assets/whatsite-package-installer-ps5.html. Enter https://speedy-away.github.io/downloads/helpers/host-package-installer/ps5/48aa27c4c9899826/whatsite-package-installer-ps5.html as its direct URL. Keep the client web service running on port 9090.
  4. Choose a PKG in the library above and open its console action. Choose a verified destination in the downloader, confirm the transfer and wait for its completion report.
  5. Open Install PKG on the completed transfer. Verify the expected size and saved file path, review the confirmation and explicitly choose Install. For an already saved PKG, open the installed package helper on your console and enter the saved file path. You can also open the file in ezRemote.

Open the ezRemote Web UI on port 9090 first if you need to install the companion. After setup, choose Open download queue. If it cannot open, check the companion path and that the matching ezRemote Server is running on port 6701. If the save folder is missing, choose Prepare a storage folder.

PS5 needs ezRemote’s bundled Direct Package Installer. The client expects it on port 9040. Check this package against the installed environment. If you still need to install ezRemote itself, follow the linked project's initial setup for your console.

The helper checks filename, size and partial download status. The SHA-256 in File details is a reference for verifying the full saved file. A native acknowledgement still requires checking the installation result on your console.
