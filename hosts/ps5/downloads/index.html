Console setup and troubleshooting

Use an existing compatible homebrew environment. The browser opens the local native tools after they have been set up.

  1. Install ezRemote Client 2.18. Start compatible websrv before opening ezRemote Client. Start the bundled background server and keep the console awake.
  2. Use the direct URL download feature in ezRemote to save the pinned downloader companion to /data/homebrew/ezremote-client/assets/whatsite-ps5.html. Its direct URL is https://speedy-away.github.io/console/ps5/whatsite-ps5.html.
  3. Choose Save on PS5 for a file, prepare or choose a writable destination and press Save to console. The local page shows the receiver queue and transfer progress.

Open installed downloader on this console. If the local page cannot open, check the companion path and that the matching ezRemote Server is running on port 6701. If the save folder is missing, choose Prepare download folder in the local downloader.

Already saved a PKG? The package setup explains the next step. Keep enough storage for both a download and any installed or extracted copy.

Choose console address

Use 127.0.0.1 on your PlayStation. From another device, enter the console’s private network address.
