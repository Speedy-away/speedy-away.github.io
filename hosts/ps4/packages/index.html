Console setup and troubleshooting

Use an existing compatible homebrew environment. The browser opens the local native tools after they have been set up.

  1. Install ezRemote Client 2.08. The background server requires a compatible GoldHEN BIN Loader. Start the bundled background server and keep the console awake.
  2. Use the direct URL download feature in ezRemote to save the latest downloader companion to /data/whatsite-ps4.html. Its direct URL is https://speedy-away.github.io/console/ps4/whatsite-ps4.html.
  3. In ezRemote, save the pinned package helper to /data/whatsite-package-installer-ps4.html. Enter https://speedy-away.github.io/downloads/helpers/host-package-installer/ps4/faa27756cd456320/whatsite-package-installer-ps4.html as its direct URL. Keep the client web service running on port 8080.
  4. Choose a PKG below and open its console action. Choose a verified destination in the downloader, confirm the transfer and wait for its completion report.
  5. Open Install PKG on the completed transfer. Verify the expected size and saved file path, review the confirmation and explicitly choose Install. For an already saved PKG, open the installed helper at /data/whatsite-package-installer-ps4.html on your console’s ezRemote Client web service (port 8080) or open the file in ezRemote.

Choose Open download queue under Installed console tools. If it cannot open, check the companion path and that the matching ezRemote Server is running on port 6701. If the save folder is missing, choose Prepare a storage folder.

The native PS4 installer can replace an existing title. PS4 firmware 14.00 compatibility with this installer still needs console verification. If you still need to install ezRemote itself, follow the linked project's initial setup for your console.

The helper checks filename, size and partial download status. The SHA-256 below is a reference for verifying the full saved file. A native acknowledgement still requires checking the installation result on your console.
