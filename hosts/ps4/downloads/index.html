Set up console downloads

Saving to your PS4 requires ezRemote and a compatible homebrew setup. Download file opens the original file in your browser. If the browser refuses the file type, use ezRemote.

First-time setup on PS4 requires a compatible GoldHEN session. The ezRemote 2.08 instructions use a prepared FAT32 USB drive to install the app. Once ezRemote is installed, the steps below run from your PS4.

  1. Open ezRemote Client 2.08 on the PS4. Enable GoldHEN BIN Loader and start the bundled background server from ezRemote Global Settings. In the console browser, choose Open ezRemote Web UI. Choose Download URL, then use Change to select the destination folder. Enter the filename and direct URL shown below.
  2. In the ezRemote Web UI, download the latest downloader companion to /data/whatsite-ps4.html. If you already installed the companion, update it at the same path. Its direct URL is https://speedy-away.github.io/console/ps4/whatsite-ps4.html.
  3. Choose Save on PS4 for a file, prepare or choose a writable destination and press Save to console. The local page shows live progress. When the save completes, eligible files show Extract or Install PKG.

Open the ezRemote Web UI on port 8080 first if you need to install the companion. After setup, choose Open download queue. If it cannot open, check the companion path and that the matching ezRemote Server is running on port 6701. If the save folder is missing, choose Prepare a storage folder.

To install a saved PKG, open the package setup and use the compatible installer. Keep enough storage for both a download and any installed or extracted copy. The native installer still needs verification on PS4 firmware 14.00.

Extract archives on PS4
  1. Keep the installed ezRemote Client and its bundled background server running.
  2. Choose Archives, select a file and wait for the local downloader to report the save complete.
  3. In the downloader, choose Extract, then Verify checksum & extract into new folder. If you reopened the downloader, select the original save folder and choose Verify & extract saved copy when it appears. Reviewed extraction keeps your original archive and creates a new folder.
  4. If the archive contains a compatible PKG, open the extracted folder in the ezRemote Web UI and select that PKG for installation. Check the result on your console.

The verified extraction action is limited to reviewed archives up to 32 MiB. For larger or unreviewed archives, inspect the saved file in the native file manager before extracting it there.

Choose console address

Use 127.0.0.1 on your PlayStation. From another device, enter the console’s private network address.
