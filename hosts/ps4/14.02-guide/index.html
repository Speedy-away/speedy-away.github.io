PS4 14.02 jailbreak

This route opens the complete upstream Afterglow build pinned at 587c00a564c4. It includes GoldHEN 2.4b18.14, the upstream-bundled ps4-hen choice and Afterglow's own cache/update flow.

Open Afterglow

Start every attempt from Afterglow

Open the landing page, choose GoldHEN or ps4-hen, then press Start. Do not bookmark or open jb.html directly: the upstream referrer guard deliberately rejects restored or direct run pages.

The published landing, run document, launcher, exploit modules, firmware offsets, patchsets and HEN files are byte-for-byte copies of the pinned upstream tree. No WWB retry, reload or settings code is injected into the allocation-sensitive run page.

Offline cache and stale copies

Afterglow uses its original HTML5 Application Cache. Let any cache update and automatic reload finish before pressing Start. The new host lives at a new immutable runtime path, so it cannot silently mix with the previous 944d5aeed06f build.

If the browser still restores an older copy, use PS4 Browser OPTIONS → Settings → Clear Website Data, reopen the short 14.02 URL and wait for the cache to finish. Clearing website data can remove other saved hosts too.

Know the failure states

A freeze or shutdown can still happen. Afterglow documents an unrecoverable kernel-allocation race. If the log says the handles are NOT defused, do not close the browser; cold-start the console. If it reports an exploit failure before the kernel stage, reopen the browser and try again manually.

If ps4-hen succeeds but launching an app freezes the console, cold-start and use GoldHEN while checking upstream. The pinned GitHub hen.bin has MD5 e7df7fb94e58a1b4a4a5e7dda4f190e1, which does not match the patched MD5 printed in the upstream README. This discrepancy is recorded rather than silently relabelling the payload.

PS4 14.02 BIN and ELF loader tools

After starting a compatible HEN, enable its BIN loader to use HTTP port 9090. The separate WebKitty ELF loader uses port 9021. Payload and game compatibility remain separate from console firmware compatibility.

Open the 14.02 loader tools. These tools are kept outside Afterglow's run document and upstream AppCache manifest.

Firmware compatibility

This host remains pinned to PS4 14.02. For 14.00 and earlier versions, use the firmware picker. Static byte checks do not replace physical-console testing.
